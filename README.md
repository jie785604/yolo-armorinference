# yolo-armorinference

\# YOLO 姿态估计装甲板推理



\## 1. 项目功能

基于 YOLO 姿态估计模型，实现对视频中装甲板的实时检测与关键点提取，并在视频中绘制检测框和骨架连线。



\## 2. 运行环境

\- Python版本：`\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\[Python 3.10.8]`

\- 主要依赖：`torch, ultralytics, opencv-python, numpy`（详见 requirements.txt）

\- 推理设备：`\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\[使用 NVIDIA RTX 5070 laptop GPU]`



\## 3. 模型权重准备与放置

\- 权重文件：`best.pt`（由Ultralytics YOLO训练生成）

\- 准备方式：在猎隼作业网站中下载文件

\- 放置位置：在项目根目录下的 `weights/best.pt`。



\## 4. 安装与运行

\- 依赖安装步骤：在项目根目录执行 `pip install -r requirements.txt`

\- 实际运行命令：`python inference.py`

\- 结果保存位置：结果视频保存在 `outputs/result.mp4`



\## 5. 视频拍摄说明

\- 拍摄地点：`\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\[西北农林科技大学水建楼D414]`

\- 视频时长：`\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\[20秒]`

\- 场景说明：`\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\[机器人在地上，装甲板在镜头前匀速旋转]`
